Frequently Asked Questions

Answers to common questions about the Study-Experiment-Assay Common Data Model (SEA-CDM), its documentation, and how to get involved. If your question isn't answered here, see the GitHub issue tracker or reach out to the He Lab directly.

General

What is SEA-CDM?

SEA-CDM (Study-Experiment-Assay Common Data Model) is a flexible common data model designed to represent complex biological studies across multiple domains. It standardizes how study metadata, experiment data, and assay outputs are represented so that data from different sources can be integrated and compared. See the home page for an overview and diagram of the model.

Who developed SEA-CDM?

SEA-CDM was initiated by the He Lab at the University of Michigan Medical School. The core developers are Anthony Huffman, Feng-Yu (Leo) Yeh, Jie Zheng, and Yongqun "Oliver" He. Full background on how the model evolved is available on the History page.

What is the DEV framework?

The Data-Entity-Variable (DEV) framework is the conceptual foundation behind SEA-CDM. It distinguishes between variables (statistical entities), data items (measured values), and real-world entities, clarifying how experimental factors relate to the data collected about them. See the History page for a full explanation and diagrams.

Is there a publication describing SEA-CDM?

Yes. Huffman A, Yeh FY, Hur J, Zheng J, Masci AM, Wu G, Tao C, Athey B, He Y. SEA CDM: Study-Experiment-Assay Common Data Model and Databases for Cross-Domain Data Integration and Analysis. Sci. Data. 2026 Jan 14;13(1):238. doi: 10.1038/s41597-026-06558-z. PMID: 41535301. PMCID: PMC12905146.

Documentation & Versions

Where can I find the full documentation of SEA-CDM classes and attributes?

Detailed documentation of every SEA-CDM class (Study, Experiment, Assay, Sample, Subject, and more), including table and column definitions, is available under SEA-CDM Versions. The current release is Version 1.4.

What versions of SEA-CDM are available, and which one should I use?

Version 1.4 is the current, actively maintained release and should be used for new work. Earlier releases, such as Version 1.3, are kept on the archived versions page for reference only.

What changed between Version 1.3 and Version 1.4?

Version 1.4 introduced the Provider and Site classes, which were not part of Version 1.3. Beyond these additions, the two versions cover the same core Study, Experiment, and Assay structure. Consult the class pages within each version for the full attribute-level details.

What core classes make up the SEA-CDM data model?

The current model (v1.4) includes: Study, Experiment, Assay, Analysis, Intervention, Occurrence, Groups, Sample, Subject, Material, Documentation, Ontology, Provider, and Site. Each class has its own documentation page describing its purpose, attributes, and relationships to other classes.

Data & Implementation

Is there a database implementation of SEA-CDM?

Yes. SEA-CDM has been implemented and tested as a MySQL relational database (OSEAN-DB), with a companion knowledge graph representation (OSEAN-KG). Both are available in the SEA-CDM GitHub organization.

Are there example datasets or use cases built on SEA-CDM?

SEA-CDM has been applied to real-world datasets, including the VIGET, ImmPort, and CellxGene use cases described in the project's GitHub repository and associated publication.

What ontologies does SEA-CDM use?

SEA-CDM reuses terms from established biomedical ontologies (such as OBI and IAO) wherever possible to identify roles, document types, and other controlled attributes. See the Ontology class documentation for details on how ontology terms are attached to variables.

Contributing & Support

Is SEA-CDM open source?

Yes. All SEA-CDM code and documentation source is publicly available on GitHub under the SEA-CDM organization, alongside the related OSEAN-DB and OSEAN-KG repositories.

How do I report a bug or request a new feature?

Please open an issue on the SEA-CDM GitHub issue tracker. Include as much detail as possible, such as the class/attribute involved and steps to reproduce the issue.

How should I cite SEA-CDM in my own work?

Please cite the primary publication: Huffman A, Yeh FY, Hur J, Zheng J, Masci AM, Wu G, Tao C, Athey B, He Y. SEA CDM: Study-Experiment-Assay Common Data Model and Databases for Cross-Domain Data Integration and Analysis. Sci. Data. 2026 Jan 14;13(1):238. doi: 10.1038/s41597-026-06558-z.
