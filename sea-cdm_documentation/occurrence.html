Occurrence

An occurrence is defined as a history that affects an organism as part of its lifespan. Occurrences include disease processes, pregnancy, and adverse events (lethal or otherwise). The Occurrence class has five core attributes: name, type, severity, start time, end time.

  • Name and type – are split to characterize different usages of occurrences. An occurrence can be listed as part of a Subject's history, as an adverse event (OAE:0000001), or pre-existing phenotype (UPHENO:0010010) for experiments.
