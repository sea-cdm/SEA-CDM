Intervention

An intervention is a planned process where one subject is subjected to a process that achieves a goal as specified in an experiment. Typically, this is done via exposure to another entity, like a drug, vaccine, environmental factor or exercise. The Intervention class has nine attributes: type, material, dosage, frequency, duration, quantity, route, intervention start, and t0 definition. However, only type, intervention start, and t0 definition are required.

The intervention type determines which attributes are to be filled:

  • Material-based interventions, e.g., vaccination (VO_0000002), involve the exposure of a material entity to a subject. These require appropriate information on dosage and route.
  • Process-based interventions, e.g., exercise or injury inductions, require duration and frequency.
  • Quantity exists for properties that are not stored as dosage, frequency, or duration.

Intervention Properties

Property Description Example Usage
intervention_id A primary key used to identify an experiment intervention. "INTER_1"
experiment_id A foreign key that is used to link an experimental intervention to an Experiment. "EXPER_1"
subject_id A foreign key that is used to link an experimental intervention to a Subject. "ORGO_1"
location_id A foreign key that is used to link an experimental intervention to an Intervention "SITE_1"
intervention_type A string used to to identify the type of intervention performed; this either emphasizes the material or duration as the key attributes. 'vaccination', 'drug administration', 'exercise intervention', 'injury induction'
intervention_type_id An uriorcurie used to identify the intervention type for material. VO:0000002, DRON:0000031, NCIT_C62739
material A string used to identify the material used as part of an intervention. "Influenza vaccine", "yellow fever virus", "Tamoxifen"
material_id An uriorcurie used to identify the ontology ID for material. VO:000642, VO:0000123, CHEBI:0014488
frequency A float used to identify how many times a subject is exposed to or participates in an intervention as part of the experiment. 0.2
frequency_unit A string used to provide the unit used to assign for frequency. days/week
frequency_unit_id A uriorcurie used to identify the ontology ID for frequency unit.
duration An unsigned float used to identify how long an intervention was administered to a subject. 0 duration represents an instantaneous intervention. 2, 3, 4
duration_unit A string used to identify the unit for a duration. hour
duration_unit_id An uriorcurie used to identify the ontology ID for duration unit. UO_0000032
dosage A float used to identify the quantity used of a material given to an organism. 2., 2.0
dosage_unit A string used to identify the unit of each quantity. "mL", "cc"
dosage_unit_id An uriorcurie used to identify the ontology ID for duration unit. IAO_0000003
quantity A list of unexpected or other measurements that are not included as existing SEA-CDM interventions. 0
quantity_units A list of strings used to identify the unit of each quantity. Celsius
quantity_unit_id A list of uriorcurie used to identify the quantity_unit_id mapped to the quantity unit. NCIT:C42559
intervention_route A string used to identify the route of administration for an experiment intervention. "Intravenous", "intranasal"
intervention_route_id A uriorcurie used to identify the ontology ID for intervention route. VO:0000574, BFO:0000049
t0_definition A string used to identify when T0 is given for intervention. "Time of administration", "Time of study"
intervention_start A double used to identify how long after the start of T0 an intervention occurred. 7
time_unit A string used to identify the unit for intervention start. "Day", "Month"
time_unit_id A uriorcurie used to identify the ontology ID for time unit. UO:000003
reference_id A string that corresponds to the intervention's ID in another dataset. Must be matched with ForeignSource. "IMM00001"
reference_source_id A string identifier that corresponds to the data source of the corresponding ForeignID. "ImmPort"
