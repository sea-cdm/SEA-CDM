Study

A study is a planned process that is intended to answer a scientific question through multiple types of experiments or observational studies. A study is the highest level of the SEA model and should link all relevant documentation and experiments together.

Study Properties

Property Description Example Usage
study_id A primary key used to represent a study. "STUDY_1"
study_name A string representing the name of a study. "OSEAN-DB Vaccine Gene Response Study"
study_description A string representing a short description of a study. This is set to 500 characters or less and is intended to illustrate the key question of a study. "A study to analyze differences in vaccine gene response data from influenza using data in OSEAN"
study_type A string representing the type of a study. 'Clinical Investigation'; 'Experimental Study'; 'Meta-Analysis'.
study_type_id An uriorcurie representing the type of a study. OBI:0500000
study_focus A string representing the intended process a study is about. 'Immune Response'; 'Infection Response'; 'Vaccine Response';
study_focus_id An uriorcurie representing the study focus. BFO:0000015
study_subject A string representing the intended subject matter shown by a study; this can be a process or material entity. 'Influenza', 'tuberculosis'
study_subject_id An uriorcurie representing the intended subject matter shown by a study. BFO:0000002
reference_id A foreign ID used to represent the source of a study from another source. Must be paired with reference_source. 'SDY562'
reference_source A string representing the reference source for a study. 'ImmPort'
comments A string used as a placeholder for extra words or comments.
