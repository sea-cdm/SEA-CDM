Analysis

An Analysis is defined as a planned process which transforms result data into a different result data. Typically, data transformation is done to analyze data from an assay that is collected from a group of samples or subjects. Alternatively, an analysis would also cover data transformations performed via computational algorithms and other forms of statistical analysis. The Analysis class contains three attributes used to characterize it: input data, file access, analysis name.

  • Input data – is used to describe the data file used to input it, and should be a subclass of 'information content entity' (IAO_0000030).
  • File access – is used to identify a download link to the transformed data.
  • Analysis name – is used to identify the method used for the data transformation (OBI_0200000).

This table contains a list of all analyses listed in a study as part of SEA-CDM. Each analysis is listed as an instance within a dataset; the same analysis from different studies will not be linked unless there is a connection between reference id values.
