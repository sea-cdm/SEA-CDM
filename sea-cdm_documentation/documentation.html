Documentation

An unsorted table used to identify all documentation (data types, protocols, or results). Documentation provides information to access the file and search the file based on its name or type of property. The text contained within the specific documentation is not stored directly within the SEA-CDM file formats. The Documentation class contains six core attributes:

  • Name – the title or label used to identify the documentation.
  • Type – refers to the purpose of the Document, and includes manuscripts, protocols and datasets for the different planned processes.
  • File access – provides a direct link to download the information.
  • Citation and citation style – meant to simplify reporting of documentation.
  • Creator name and creator role – paired; typically the creator's role is either the 'reporting agent role' (OBI:0000068) for creators which uploaded or wrote the file or 'responsible party role' (OBI:00000102) if only the publisher is known.
