Groups

A group is defined as a collection of multiple individual instances that are grouped as part of an analysis. The Group class has six core attributes: composition, subject group type, sample group type, minimum age, maximum age, and group size.

A Group's sample group type is meant to identify the common feature of the selected subjects, either within one experiment or across multiple experiments. Similarly, the usage of minimum and maximum age is used due to how human cohorts indicate age ranges for privacy. For non-human subjects, the minimum and maximum ages can be calculated from the sample group.

A Group's sample group type is meant to distinguish between the usage of a biosample or expsample for the creation of a group.

Group Properties

Property Description Example Usage
group_id A primary key used to identify a specific group. "GROUP_1"
subject_group_type A string representing if a group is about an organism or sample. "Organism", "Population"
subject_group_type_id A string used to identify the ontology id that corresponds to a group type. OBI_0001479, OBI_0100079
sample_group_type A string representing if a group is about an organism or sample. "Biosample", "Expsample"
sample_group_type_id A string used to identify the ontology id that corresponds to a group type. OBI_0100051
composition A value that describes the nature of the group as a collection of instances for the same organism, multiple experimental replicates, or a heterogeneous group. "Sample", "Organism"
group_size A value that stores how many individual organisms are contained within a group. 36
min_group_age A double that records the youngest age of an organism or a sample derived from an organism in a group. 17
min_age_unit A string represent the unit associated with the min_group_age "Day", "Month"
min_age_unit_id A string represent the ontology id min_age_unit.
max_group_age A double that records the youngest age of an organism or a sample derived from an organism in a group. 87
max_age_unit A string represent the unit associated with the max_group_age "Day", "Month"
max_age_unit_id A string represent the ontology id max_age_unit. UO:0000035, UO:0000033
reference_id A string used to identify an external reference for the group. "ARM512"
reference_source A string used to identify the source of the reference_id. "ImmPort"
