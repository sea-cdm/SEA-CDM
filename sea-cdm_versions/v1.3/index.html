SEA-CDM Version 1.3 Documentation

This contains the documentation for the different tables found in SEA-CDM Version 1.3. This includes a textual description of each table, the columns contained within a table, and the annotations for each column.

Each column also has a default ontology ID that is used as a parent class for each entry. Bolded ontology IDs are the parent for all compliant ontology IDs. This may be used as a placeholder for people using the SEA-CDM model.
