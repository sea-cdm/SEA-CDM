Experiment

An Experiment is a planned process that contains all Interventions performed on a Subject in preparation for all Assays. The Experiment class can include clinical visits, experimental controls, and experimental changes. The Experiment class contains three attributes:

  • Type – determines the intended outcome for an experiment; i.e. is it to gather information for diagnosis in a clinical visit or a scientific experiment to answer a hypothesis.
  • Subject – describes the subject focus of an experiment; this may be a specific trait or subject (if multiple traits about the subject are being investigated).
  • Experiment control – denotes if the procedure for an Experiment is intended to serve as a control; i.e. otherwise lacking a specific intervention compared to other Experiments.

Experiment Properties

Property Description Example Usage
experiment_id An primary key that corresponds to an instance of an experiment. "EXPER_1"
study_id A foreign key that corresponds to a study an experiment belongs to. "STUDY_1"
documentation_id A foreign key that corresponds to a document that describes the protocol used as part of this experiment. "DOCU_1"
experiment_control A binary flag used to indicate if an experiment row is used as part of an experimental control or not. "True", "False"
experiment_subject A string used to represent the subject focus used for an experiment. "humans", "cell lines"
experiment_subject_id An uriorcurie used to match experiment_subject to an ontology ID. NCBITaxon:9606
experiment_type A string used to describe the type of an experiment performed. "Clinical Visit", "Experiment"
experiment_type_id An uriorcurie used to match experiment_type to an ontology ID. OBI:0500000
reference_id A foreign ID used to represent the source of an experiment from another source. Must be paired with reference_source. "ARM_0000002"
reference_source A string representing the reference source for an experiment. ImmPort
comments A string used as a placeholder for extra words.
