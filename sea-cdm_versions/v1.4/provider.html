Provider

A Provider is defined as a material entity that act as agents that performs an Experiment. Typically, this is done for Experiments that are clinical visits, though this can be stored for other experiments. The Provider class contains five attributes: type, role, date of birth, gender, and sponsor.

  • Type – represents the type of entity, typically and traditionally a person (SIO_0000498), or an organization. This would also denote artificial agents that may be assigned for such tasks.
  • Role – represents the role the provider performed, either for diagnosis or medical treatment (SIO_0000395) or researcher (BAO_01650001).
  • Gender – should correspond to the social gender of the provider; the usage of sex phenotype can be used when both align (PATO_0000384).
  • Date of birth – should correspond to the provider's birth date, if the provider is a person.
  • Sponsor – should correspond to either the institution that employs or provided payment for the sponsor for their role in the experiment.

Provider Properties

Property Description Example Usage
provider_id An internal ID that is used to identify the provider in SEA-CDM. "JOB_1"
provider_type A string representing the material entity that is a provider. "person"
provider_type_id The associated ontology ID linked with the provider_type attribute. SIO:0000498
provider_role A string representing the role of a provider within an Experiment. "doctor", "researcher"
provider_role_id An uriorcurie representing the provider role. SIO:0000395, BAO:01650001
provider_date_of_birth A date value representing the birth or creation of a provider. This value should only be used for person providers. 2020-05-26
provider_gender A string representing the social gender of a provider; organizations and AI agents are designated different orders. "Male"
provider_gender_id An uriorcurie representing the provider gender. PATO:0000384
provider_sponsor A string representing the affiliation or organization that a provider acted upon for an experiment. "University of Michigan"
provider_source_value A string used as an ID to represent the provider in a different database. 15315
provider_source_reference A string representing the organization that issued the provider source value. "OMOP"
