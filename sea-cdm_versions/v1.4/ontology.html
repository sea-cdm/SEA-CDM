Ontology

This table contains a list of all ontologies used for a SEA CDM. Ontologies are special forms of documentation that are meant to be directly queried by SEA CDM to link IDs to knowledge graphs and are utilized by SEA-CDM Schema for rule-based restrictions. Further information is meant to be queried or linked according to work done in SEA CDM.

Ontology Properties

Property Description Example Usage
ontology_id A primary key used internally to identify a specific ontology. "ONTO_1"
documentation_id An foreign key used to identify the documentation associated with the ontology. "DOCU_1"
ontology_name A string used to provide the common name that is used as an ontology. "Ontology of Biomedical Investigations",
"Ontology of Precision Medical Investigation",
"Vaccine Ontology"
ontology_iri A string used to identify the ontology IRI that is used for terms within a specific ontology. http://purl.obolibrary.org/obo/OBI
