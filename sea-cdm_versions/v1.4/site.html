Site

A site is an immaterial entity that is used to identify the location a planned process occurs in. The Site class has four core attributes: name, type, trait, location.

  • Trait – denotes any environmental variables (e.g., temperature) that are reported.
  • Location – is split across location, location_type, and location_country. The location type is meant to specify if a location is a set co-ordinate, address, room, or smaller locations. The latter is reported due to experimental cohorts being sorted by different countries.

Site Properties

Property Description Example Usage
site_id An internal id that is used to identify the site in SEA-CDM. "SITE_001"
site_name A string representing the name of the location that the site covers. "University of Michigan Medicine"
site_type A string used an id to represent the relevant occurrences performed at a site. "Laboratory, hospital"
site_type_id An uriorcurie linked with the site_type attribute. OBI:0003250
site_trait A string representing a trait associated with the site; these are typically environmental factors. "Temperature"
site_trait_id An uriorcurie representing the site trait. PATO:0000146
site_trait_value A list of strings representing the value recorded for site traits. "27"
site_trait_value_unit A list of strings representing the unit associated with the site trait. "Celsius"
site_trait_value_unit_id A list of uriorcurie representing the site trait value. NCIT:C41141
site_location A string used to represent the site location; format is determined by site_location_type. "2800 Plymouth Road; Ann Arbor; MI; 48109"
site_location_type A string used an id to represent the site in a different database; is it an address, co-ordinates, etc. "Address"
site_location_id The uriorcurie linked with the site_location_Identifier attribute. NCIT:C25690
site_country_id A string representing the alpha-3 code (ISO-3166). "USA", "CHN"
