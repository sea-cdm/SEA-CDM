Subject

A Subject is defined as a material entity that is exposed to an Intervention and is used as an input, or generates the input via Sample, for an Assay. The Subject class contains eight attributes used to characterize it: subject type, subject quantity, species, age, sex, breed, or race.

  • Type – determines what kind of entity it is; typically it an organism (OBI_0100026), or cell line. A population of organisms (OBI_0000181), either done as biological replicates or parts of a group, should be labeled by its components.
  • Quantity – determines if it represents a population or a single entity; i.e. a quantity of 1 indicates the Subject represents a group of entities that share the same characteristics.
  • Species – must use the NCBITaxon ID used to characterize an organism.
  • Age – is split into a float and unit used to characterize their age when first enrolled or recorded as part of the Experiment (1 day, 2 months, 5 years etc.).
  • Sex – corresponds to its biological sex, and for humans would typically be male (PATO_0000384) and female (PATO_00000383). If this information is unknown or it has a non-male or non-female biological sex, the biological sex (PATO_0000047) should be used to represent that information is known. Specific gender presentation would be listed as an Occurrence.
  • Breed – represents a specific biological ancestry or lineage of interest to reporters (e.g. BALB/C mouse, Omicron-SARS-CoV-2, Human Haplotype, etc.). If no specific lineage is recorded, use the Organism's species ID.
  • Race – represents a cultural identifier that doesn't have a consistent definition and can also represent human castes.

This table contains a list of all subjects listed in an experiment as part of the SEA CDM. Each subject is listed as an instance within a dataset; the same organism from different studies will not be linked unless there is a connection between foreign_id values. This instance of Subject is focused strictly on biological subjects.

Subject Properties

Property Description Example Usage
subject_id An internal ID that corresponds to an instance of a subject. "SUBJ_1"
experiment_id A foreign key that corresponds to which experiment a subject belongs to. "EXPER_1"
group_id A foreign key that corresponds to which group a subject belongs to; subjects that do not belong to a group are assigned a group value of 1 (to represent a singleton). "GROUP_1"
subject_type A string represented by the type of subject; this can include individuals or populations that share characteristics. "organism", "population"
subject_type_id A uriorcurie that corresponds to the subject_type. OBI_0100026, OBI_0000181
subject_quantity An integer representing the population size of a subject; if the subject is a single entity, record as 1. 1, 6
species A string representing the species a subject belongs to; this is a common name that is listed. "Human"
species_id A string representing the species a subject belongs to; this species is identified as equivalent to "OBI_0100026". NCBITaxon:9606
