Results

Results are data content entities generated from an assay, analysis of an assay, or an analysis on data that is derived from an assay. The Results class has seven core attributes: analysis type, original assay type, datatype, dataset size, file access, file type, dataset size, file access.

  • Analysis type and original assay type – are meant to characterize how the initial data was characterized and then transformed.
  • Dataset size – is meant to store the internal dimensions of the file and not the memory needed to load a file.

Results Properties

Property Description Example Usage
results_id An internal ID used to identify assay results in a database. "RSULT_1"
experiment_id An foreign key used to identify the experiment an assay result is part of. "EXPER_1"
group_id An ID used to identify the group an assay result is about. Groups that are about individual organisms or samples are given a special ID. "GROUP_1"
sample_id A foreign key used to identify the sample result is about. If used for a group, use "1" as placeholder value. "SAMP_1"
subject_id A foreign key used to identify the subject results is about. If used for a group, use "1" as placeholder value. "ORGO_1"
documenation_id An foreign key used to identify the document that contains the documentation for the sort. "DOCU_1"
analysis_type A string used to identify the current analysis used to generate a result. Observation, Statistical-Analysis
original_assay_type A string used to identify the original assay type used to generate an assay. This is always an experimental assay. "Blood.RNA Assay",
"Sequence feature detection assay"
original_assay_type_id An ID used to identify the assay ID that an OriginalAssayType is part of. OBI:0000433,
OBI:0000070
datatype A string used to identify the type of data the results is; either numeric, qualitative, etc. 'Text', 'Figure', 'Image', 'Tensor'
datatype_id An ontology ID that corresponds to the Datatype. IAO:0000101,
IAO:0000030
dataset_size A string used to identify the size of a document. Currently used as a string due to variable size from matrices or hierarchical data. "9000", "402x27", "305x25x200"
file_access A string used to identify the location or web link the results file is located. This is analogous to reference_source in other values. https://zenodo.org/records/7407195
file_type A string used to identify the file type extension the data is stored as (if accessible for computers). ".csv"
replications An integer that lists how many times an analysis is repeated to generate data; multiple measurements. 1
